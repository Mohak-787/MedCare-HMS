# MedCare-HMS

A hospital management system backend with authentication, OTP verification, and user profile APIs.

## Documentation

- [Auth API](docs/auth.md)
- [OTP API](docs/otp.md)
- [User API](docs/user.md)

## Quick Start

```bash
pnpm install
pnpm dev
```

The API is mounted at:

```text
http://localhost:3001/api
```

Required environment variables are listed in [.env.example](.env.example).
